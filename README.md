# Rueda Libre

Sitio web accesible para alquiler de bicicletas, reservas, tarifas y recorridos en Medellín.

La aplicación está construida con HTML y CSS, sin JavaScript. Incluye la página de inicio, el formulario de reservas, contacto, tarifas y rutas, y una comparación de layouts responsive.

Sitio publicado: https://jhoimarosorio.github.io/rueda_libre/

## Contenido

- `index.html`: inicio.
- `paginas/reservas.html`: selección de bicicletas y formulario de reserva.
- `paginas/contactanos.html`: formulario de contacto.
- `paginas/tarifas.html`: tarifas y recorridos.
- `comparacion-css.html`: comparación de grillas CSS y Bootstrap.
- `bitacora.txt`: pruebas, auditoría de accesibilidad y mapa de contraste.
